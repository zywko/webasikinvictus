Development Tools and Terminal Commands

This site was authored completely in plain HTML5 without any CSS styling, framework templates, or build tools. All files were created in a lightweight text editor and tested locally in Google Chrome and Mozilla Firefox.

To commit changes into the local version control repository, I ran the following command in my terminal: 

git status
git add index.html memberships.html booking.html colophon.html
git commit -m "feat: complete initial HTML markup"

To inspect source code directly inside the browser, press Ctrl + U on Windows or Cmd + Option + U on macOS. When checking network requests, the terminal sample output looked like:

Console output: GET /index.html 200 OK - 4.2ms

The underlying skeleton relies strictly on semantic tags like <header>, <nav>, <main>, and <footer>.

Validation and Code Integrity

W3C Conformance

Every document has been checked against the official W3C Nu HTML Checker. No custom inline styles or script tags were inserted. Colors and layout will be introduced in subsequent coursework assignments.
